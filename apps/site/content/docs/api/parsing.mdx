## lint

```ts
lint(commands: readonly Command[], media?: LintMedia): LintDiagnostic[]
```

Finds problems the printer wouldn't report in commands from `parse()` or `label.commands`, and returns a list of `LintDiagnostic`s. `media` is the printer's media size, for labels that don't set `^PW` or `^LL`:

## serialize

```ts
serialize(commands: Command[], options?: { minify?: boolean }): string
```

Turns command nodes back into ZPL. Pass `{ minify: false }` to put each command on its own line.

## format

```ts
format(zpl: string): string
```

Lays out ZPL to read: one field or setting per line, and a blank line between labels. Unlike `serialize()`, it keeps the ZPL as written, only moving line breaks, so the labels print the same.

```ts
format("^XA^PW406^FO20,20^A0N,40^FDHi^FS^XZ");
// ^XA
// ^PW406
// ^FO20,20^A0N,40^FDHi^FS
// ^XZ
```
