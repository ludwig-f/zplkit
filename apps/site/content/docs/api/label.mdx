```ts
import { Label, mm, dots, Orientation, ZebraFontFamily } from "@zplkit/core";
```

`Label` builds one label as a list of ZPL commands. Each drawing method adds a field and returns the label, so calls chain. [Method calls](/docs/building-labels) introduces it; this page lists every method and option.

## new Label(options)

```ts
new Label(options: LabelOptions): Label
```

```ts
const label = new Label({ width: mm(101.6), height: mm(152.4), dpmm: 8 });
```

## Methods

| Method | ZPL | Adds |

| [`text`](#text) | `^A`, `^FD` | Text |

| [`lint`](#output) | | Problems the printer won't report |

## Drawing

### text

```ts
label.text(options: TextOptions): this
```

Adds text in one of the printer's fonts or a font file on the printer. Characters ZPL would read as commands are escaped.

```ts
label.text({
  position: { x: mm(5), y: mm(5) },
  text: "Harbor Parts Co.",
  font: { height: mm(5) },
});
```

### field

```ts
label.field(options: FieldOptions): this
```

Adds a field with any command, for elements without their own method. The command is added as written, and the data is escaped.

```ts
label.field({
  position: { x: mm(5), y: mm(5) },
  command: "^B8N,100,Y,N",
  data: "1234567",
});
```

## Barcodes

The linear barcodes take these options. The 2D codes take `position`, `data` and `orientation`, plus the options listed with them.

### code128

```ts
label.code128(options: Code128Options): this
```

Code 128, the general-purpose barcode for letters, digits and punctuation. Shipping and logistics labels use it most. Writes `^BC`.

```ts

  position: { x: mm(5), y: mm(5) },
  data: "ORD-10442",
  height: mm(12),
```

### upcEanExtension

```ts
label.upcEanExtension(options: UpcEanExtensionOptions): this
```

The 2 or 5 digit add-on printed to the right of a UPC or EAN code, for example a magazine's issue number. Give it its own position, a little lower and shorter than the main code. Its digits print above the bars by default. Writes `^BS`.

```ts
label.upcEanExtension({
  position: { x: mm(5), y: mm(5) },
  data: "04414",
});
```

It takes only the options above.

### postnet

```ts
label.postnet(options: PostnetOptions): this
```

USPS POSTNET: a ZIP code of 5, 9 or 11 digits as tall and short bars. The printer adds the check digit, and doesn't print the digits unless `printHri` is set. Writes `^BZ`.

```ts
label.postnet({
  position: { x: mm(5), y: mm(5) },
  data: "12345",
  height: dots(40),
});
```

It takes the linear barcode options above, with `printHri` off by default.

### intelligentMail

```ts
label.intelligentMail(options: IntelligentMailOptions): this
```

USPS Intelligent Mail: a 20 digit tracking code followed by a routing code of 0, 5, 9 or 11 digits. Writes `^BZ`.

```ts
label.intelligentMail({
  position: { x: mm(5), y: mm(5) },
  data: "00123123456123456789",
  height: dots(40),
});
```

It takes `position`, `data`, `orientation` and `height`, and never prints its digits.

## Output

| Method | Returns |
| --- | --- |
| `toZPL()` | The ZPL, closed with `^XZ` if it isn't already |
| `lint()` | Problems the printer won't report, as [`LintDiagnostic`](/docs/api/parsing#lintdiagnostic)s |
| `validate(strict?)` | Nothing; throws a `ZplError` for unclosed fields, and with `strict` (the default) for unknown commands |
| `commands` | The label's command nodes |

## Lower level

| Method | Adds |
| --- | --- |
| `add(...commands)` | Typed command nodes, as written. Nothing is escaped. |
| `raw(zpl)` | Plain ZPL, as written. Nothing is escaped, so keep user input out. |
| `open()`, `close()` | `^XA` and `^XZ`, for several formats in one label |
