```ts
import { Label, Text, Box, Code128, build, mm, dots } from "@zplkit/core/jsx";
```

[JSX](/docs/jsx) shows how to set it up and build labels. Elements take the same options as the [Label](/docs/api/label) methods, with `x` and `y` instead of `position`, and text or barcode data as children.

## build(element)

Turns a `<Label>` element, or a component that returns one, into a [`Label`](/docs/api/label), with `toZPL()`, `lint()` and `commands`. It throws a `ZplError` for anything else, or for text outside a `<Text>`.
