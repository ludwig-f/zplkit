ZPL (Zebra Programming Language) is the text format thermal label printers understand. A label is a stream of commands like `^FO50,50` (move to 50, 50) and `^FDHello^FS` (print "Hello"). The printer reads the text and draws the label itself, dot by dot.

Writing ZPL by hand is fiddly, and printers don't report mistakes: they quietly clamp values, skip fields or print nothing at all. zplkit helps at each step:

## Packages

| Package | What it does |
| --- | --- |
| `@zplkit/core` | Build labels with JSX or method calls, parse and lint ZPL |
| `@zplkit/render` | Renders ZPL to images in Node or the browser, the way a printer draws it |
| `@zplkit/preview` | `<zpl-preview>`, a web component that renders ZPL in the browser |
| `@zplkit/print` | Sends labels to printers and reads their status, over the network, USB or Bluetooth ([experimental](/docs/printing)) |
| `@zplkit/mcp` | An MCP server that lets AI assistants render, lint and convert labels, and look commands up ([AI assistants](/docs/mcp)) |
| `@zplkit/cli` | The `zplkit` command: render, preview, lint, convert and print labels from a terminal ([command line](/docs/cli)) |

All of them are ES modules and need Node 22 or newer. They're open source under the MIT license; the code is on [GitHub](https://github.com/ludwig-f/zplkit).

To try zplkit without installing anything, write a label in the [playground](/playground). To see existing ZPL, paste it into the [ZPL viewer](/viewer).
